# api-file-color project

## Uses the FastAPI Python API library to create an API
Features:

- Allows uses to easily replace or change color codes in files such as .txt, .JSON, .CSS, .HTML, and so on.
- Users can limit the changes made via a blacklist or whitelist option.
- You can change CSS standard color names such as 'blue' to a hexadecimal or rgb string.
- Allows a color swapping feature to quicly create new colors based existing ones, allowing you to change files
  rapidly when you need new starting colors.
